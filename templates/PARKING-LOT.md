# PARKING LOT — idea capture, zero ceremony

Protocol: the human says an idea the MOMENT they think it — mid-dispatch, mid-verify,
mid-anything — optionally prefixed "PARK:". The mentor appends it here near-VERBATIM
(paraphrase drift is a known bug class) + one line of context, then returns to the live
thread. Builder-wait windows = triage/spec windows for items below. Slice boundaries =
pick-next moments.

An item leaves this file only by: promotion (→ spec/dispatch, note where), merge into an
existing tracked item (note which), or an explicit kill by the human.

Format:
## YYYY-MM-DD HH:MM — <short handle>
> The human's words, near-verbatim
Context: <what was happening / what it relates to>
Status: PARKED | PROMOTED → <where> | KILLED (<why>)
